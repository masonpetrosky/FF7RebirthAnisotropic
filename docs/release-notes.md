Raises the anisotropic filtering of FINAL FANTASY VII REBIRTH's textures from the game's fixed 4x to 16x, so floors, roads and other surfaces seen at a shallow angle stay sharp further from the camera.

**Requires ReShade 6.x with full add-on support** (DirectX 12). Extract the zip into `...\FINAL FANTASY VII REBIRTH\End\Binaries\Win64`. The game creates its texture samplers when it starts, so a changed level applies from the next start. Tested with game build 23447986 (Steam, October 2026) and ReShade 6.8.0. See the README for details and settings.
